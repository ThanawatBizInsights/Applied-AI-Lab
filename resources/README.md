# Resources

- [`RESOURCE_LIBRARY.md`](RESOURCE_LIBRARY.md): curated courses, documentation and references,
  with module mapping, difficulty, time and **verification status**.
- Week-specific lists: each week's `RESOURCES.md`.

To add a resource, give: title, author or organisation, URL, module, difficulty, estimated time,
why it is relevant, and the date you verified it (or "Not yet verified").
