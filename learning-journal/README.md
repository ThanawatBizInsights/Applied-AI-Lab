# Learning journal

One file per week: `week-XX.md`, copied from [`templates/JOURNAL_TEMPLATE.md`](../templates/JOURNAL_TEMPLATE.md).
Log actual hours per session (these feed `PROGRESS.md`), what you tried, what broke, and what you
learned. Write honestly: this is evidence of learning, not a report for anyone else.

Do not put personal data about others, customers or children here.
