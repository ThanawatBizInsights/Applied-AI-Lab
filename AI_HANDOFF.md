## 6. Architectural decisions
- ADR-001: one learning repository; production project repositories stay read-only from here.
- ADR-002: provider-independent `LLMClient` interface from Week 1, with a fake client by default.
- ADR-003: brand rules as validated JSON data.
- Week outlines are generated by `scripts/scaffold.py`, which **never overwrites** files, so
  hand-expanded weeks are safe.
- Assignment tests are marked `assignment` and are deselected by default (`pyproject.toml`), so
  `uv run pytest` stays green while the learner's TODOs are unfinished.
- The Week 1 assignment tests were checked against a private reference solution, which was then
  deleted. **No solutions are in the repository.**
