# Evaluations

| Folder | Contents |
|---|---|
| `datasets/` | small synthetic or public evaluation sets + dataset cards (`templates/DATASET_CARD.md`) |
| `benchmarks/` | benchmark definitions and the model registry (`model-registry.csv`) |
| `metrics/` | metric definitions used across weeks (`METRICS.md`) |
| `reports/` | evaluation reports (`templates/EVALUATION_REPORT.md`), e.g. `w01-brand-assistant.md` |

Datasets > 5 MB do not go in Git. Sensitive domains use synthetic data only.
