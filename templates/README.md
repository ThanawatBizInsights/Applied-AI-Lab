# Templates

| Template | Use for |
|---|---|
| `WEEK_TEMPLATE.md` | expanding a week's full materials (checklist and section skeletons) |
| `EXPERIMENT_TEMPLATE.md` | a new experiment (all required sections) |
| `results_template.csv` / `results_template.json` | quantitative results (one row per observation / summary) |
| `REVIEW_TEMPLATE.md` | Review Mode reports (ChatGPT, Claude or self-review) |
| `JOURNAL_TEMPLATE.md` | weekly learning journal |
| `DATASET_CARD.md` | documenting an evaluation or training dataset |
| `EVALUATION_REPORT.md` | evaluation reports in `evaluations/reports/` |
| `PROJECT_CONTEXT_TEMPLATE.md` | adding a new project workspace |
