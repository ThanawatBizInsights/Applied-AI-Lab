## [VERIFIED] What the repository shows
- **Billionslight Animation Studio**: a local-first, programmable low-poly 3D animation engine that turns Thai educational scripts about solar energy and electricity into vertical videos (Reels, TikTok, Shorts).
- Stack: Remotion 4.0.547 with React Three Fiber and three.js; episodes are validated JSON (zod); vitest tests; renders verified with ffprobe.
- `docs/electrical-accuracy.md` encodes electrical rules used in a validation stage.
- README status: Phase 1 (technical foundation) complete, awaiting approval. Supports Intel macOS with software GL.
