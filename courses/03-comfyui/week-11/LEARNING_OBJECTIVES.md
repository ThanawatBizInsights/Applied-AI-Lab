# Week 11 — Learning objectives

By the end of this week you should be able to:

1. Build a character dataset with captions, varied poses and consistent identity.
2. Train a character LoRA and choose rank, steps and learning rate with evidence.
3. Measure identity consistency with embedding similarity and human rubrics.
4. Run EXP-03 (identity with vs without LoRA).

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
