# Week 12 — Learning objectives

By the end of this week you should be able to:

1. Explain how image-to-video models add temporal consistency.
2. Control camera movement and keyframes for storyboard shots.
3. Upscale images and video, with an understanding of the artefacts.
4. Drive ComfyUI headlessly via its HTTP/WebSocket API for batch jobs.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
