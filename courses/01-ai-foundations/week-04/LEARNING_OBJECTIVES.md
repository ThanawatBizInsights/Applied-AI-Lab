# Week 04 — Learning objectives

By the end of this week you should be able to:

1. Explain how tool calling works at the protocol level (the model proposes, your code executes).
2. Implement a provider-agnostic gateway interface with retries, timeouts and usage accounting.
3. Route requests by task type, cost and measured quality.
4. Build a benchmark harness with fixed datasets, metrics and versioned results.
5. Complete EXP-01 (Thai LLM accuracy and cost) with a written report.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
