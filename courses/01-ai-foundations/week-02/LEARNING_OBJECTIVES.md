# Week 02 — Learning objectives

By the end of this week you should be able to:

1. Explain a neuron, a layer, a loss function and gradient descent, and implement a two-layer network in NumPy.
2. Explain self-attention (queries, keys, values, softmax) and why transformers replaced RNNs.
3. Compare BPE and SentencePiece tokenisers and measure how many tokens Thai text costs compared with English.
4. Explain autoregressive decoding, temperature, top-p, the KV cache and why output tokens cost more than input tokens.
5. Relate context length, token counts and latency to real API cost for a Balena caption job.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
