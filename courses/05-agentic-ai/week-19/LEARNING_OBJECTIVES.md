# Week 19 — Learning objectives

By the end of this week you should be able to:

1. Explain MCP's architecture: hosts, clients, servers; tools, resources, prompts.
2. Explain the transports (stdio, streamable HTTP) and the security model.
3. Build a Python MCP server that exposes the Knowledge Engine as tools and resources.
4. Test servers with the MCP Inspector and automated tests.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
