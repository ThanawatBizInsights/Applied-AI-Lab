# Week 18 — Learning objectives

By the end of this week you should be able to:

1. Distinguish workflows from agents and choose the simpler one when it is enough.
2. Implement an agent loop with planning, tools, state and stopping conditions.
3. Implement short-term and long-term memory and explain the risks.
4. Build a LangGraph agent with checkpointed state and human interrupts.
5. Design EXP-06 (single-agent vs multi-agent).

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
