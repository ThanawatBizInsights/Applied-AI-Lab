# Week 23 — Learning objectives

By the end of this week you should be able to:

1. Threat-model the platform with the OWASP LLM Top 10.
2. Add tracing, structured logs and dashboards for LLM calls.
3. Build a regression evaluation suite that runs in CI.
4. Reduce cost with caching, routing and prompt optimisation, with measured savings.

## Competencies affected (see `PROGRESS.md`)

commit, test or report.
