# Week 14 — Learning objectives

By the end of this week you should be able to:

1. Explain the OAuth 2.0 authorisation-code flow and token refresh.
2. Receive and verify webhooks (signatures, replay protection).
3. Read and write Supabase rows safely from n8n with row-level security in mind.
4. Organise files in Google Drive automatically with metadata.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
