# Week 16 — Learning objectives

By the end of this week you should be able to:

1. Design workflows that fail safely: retries, dead-letter queues, alerts.
2. Implement human-in-the-loop approval with an audit trail.
3. Add structured logging and run metrics to automations.
4. Apply automation to CheckKhum renewals and quotations with mandatory staff approval.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
