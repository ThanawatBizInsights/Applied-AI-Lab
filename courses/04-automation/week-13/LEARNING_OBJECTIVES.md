# Week 13 — Learning objectives

By the end of this week you should be able to:

1. Explain workflow automation concepts: triggers, items, nodes, executions.
2. Run n8n locally in Docker with persistent storage.
3. Write n8n expressions and Code nodes that transform JSON items.
4. Version workflows as JSON in Git without credentials.
5. Start the EXP-08 baseline: log manual task times.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
