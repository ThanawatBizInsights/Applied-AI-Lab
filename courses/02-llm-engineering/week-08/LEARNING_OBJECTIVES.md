# Week 08 — Learning objectives

By the end of this week you should be able to:

1. Decide between prompting, RAG and fine-tuning for a given problem, with reasons.
2. Explain LoRA's low-rank update and QLoRA's 4-bit base model.
3. Fine-tune a small open model on a cloud GPU with a held-out evaluation.
4. Explain quantisation formats (int8, 4-bit, GGUF) and their quality and latency trade-offs.
5. Document model licences and commercial-use limits.

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
