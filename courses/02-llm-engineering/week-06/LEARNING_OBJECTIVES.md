# Week 06 — Learning objectives

By the end of this week you should be able to:

1. Explain the RAG architecture and the failure modes at each stage.
2. Extract text and tables from PDFs, including Thai PDFs with encoding problems.
3. Compare fixed, recursive, semantic and structure-aware chunking.
4. Build an end-to-end RAG pipeline that answers only from retrieved context.
5. Design EXP-02 (RAG vs standard LLM).

## Competencies affected (see `PROGRESS.md`)
Evidence from this week can raise competencies by **at most one level**, and only with a linked
commit, test or report.
